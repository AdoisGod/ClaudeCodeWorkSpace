## Financial Sentiment Keywords

### Revenue Indicators
**Positive**: growth, increase, strong, robust, solid, up, record, beat, exceed, outperform, acceleration
**Negative**: decline, decrease, down, weak, soft, miss, below, pressure, slowdown, deceleration

### Margin Indicators
**Positive**: expansion, improve, improvement, leverage, strong, healthy, accretive, operating leverage
**Negative**: pressure, compression, decline, headwind, challenge, dilutive, impact, deterioration

### Guidance Indicators
**Positive**: raise, raised, increase, upside, optimistic, strong outlook, confident, accelerate, upgrading
**Negative**: lower, lowered, reduce, cautious, uncertainty, below, conservative, decelerate, downgrading

## Customization

To add custom themes, tell Claude:
```
"也追蹤以下主題: [theme name] - [keyword1, keyword2, ...]"
```

Example:
```
"也追蹤 'Quantum Computing' - quantum, qubit, quantum computer"
```
