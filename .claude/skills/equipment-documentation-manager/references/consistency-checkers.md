# 一致性檢查指南

## 使用時機
- 新增/修改文件後
- 定期檢查（每週/雙週）
- 交付前驗證

---

## 檢查項目

### 1. 交叉引用檢查

**檢查內容**：
- 序列中提到的軸/感測器是否在 20 層定義
- 引用的 MR/DM 位址是否在 50 層定義
- 「詳見 XX.md」的文件是否存在

**檢查方法**：
```
1. 列出 30 層文件中所有元件名稱
2. 確認每個名稱在 20 層有定義
3. 列出所有「詳見 XX.md」引用
4. 確認被引用文件存在且內容對應
```

**輸出格式**：
```
✅ Conv_Y1: 定義於 20-axes-specs.md
✅ MR1100: 定義於 53-photo-handshake.md
❌ NewAxis_X: 未在 20 層定義
```

---

### 2. 記憶體位址檢查

**檢查內容**：
- DM 位址範圍是否重疊
- MR 位址是否重複使用
- 位址是否超出 PLC 容量

**檢查方法**：
```
1. 彙整所有 50 層文件的位址分配
2. 排序後檢查是否有重疊
3. 確認總用量未超出限制
```

**輸出格式**：
```
DM 分配：
✅ DM1000-1999: Conv_Y1 參數
✅ DM2000-2999: Conv_Y2 參數
❌ DM5500-5600: 重疊！同時被 Zone1 和 GT2 使用

MR 分配：
✅ MR1100-1103: SEQ-101
❌ MR1200: 重複！被 SEQ-105 和碰撞旗標同時使用
```

---

### 3. 版本同步檢查

**檢查內容**：
- 相關文件版本是否同步更新
- 修改日期是否合理
- README 索引是否更新

**檢查方法**：
```
1. 找出最近修改的文件
2. 依據依賴關係，確認相關文件是否需要更新
3. 確認 README 反映最新狀態
```

**輸出格式**：
```
最近修改：20-axes-specs.md（新增 HLight_Z2）

影響檢查：
✅ 30-stage1.md: 無需更新（尚未使用新軸）
⚠️ 50-plc-memory-map.md: 需要分配新軸位址
⚠️ 00-README.md: 需要更新軸數統計
```

---

## 檢查頻率建議

| 頻率 | 檢查項目 |
|------|---------|
| 每次修改後 | 交叉引用（修改相關部分）|
| 每週 | 記憶體位址 |
| 每雙週 | 完整交叉引用 |
| 交付前 | 全部檢查項目 |

---

## 快速檢查指令

### 列出所有待引用項目
```bash
grep -r "詳見\|參考\|見 " *.md | grep "\.md"
```

### 列出所有 DM/MR 位址
```bash
grep -rE "DM[0-9]+|MR[0-9]+" *.md
```

### 檢查版本記錄
```bash
grep -A 5 "版本記錄" *.md
```
