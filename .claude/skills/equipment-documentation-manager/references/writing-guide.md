## 表格格式規範

### 欄位數量
- **3 欄**：簡單對照（編號、名稱、說明）
- **4 欄**：標準規格（編號、名稱、規格、備註）
- **5 欄以上**：考慮是否該拆分或簡化

### 表格內文字
- 保持簡潔，每格不超過 20 字
- 需要詳細說明時，在表格外另開小節

## 版本號規則

| 變更類型 | 版本變化 | 範例 |
|---------|---------|------|
| 重大架構調整 | X.0 → (X+1).0 | v1.0 → v2.0 |
| 內容新增/修改 | X.Y → X.(Y+1) | v2.0 → v2.1 |
| 格式調整/錯字 | 不變版本號 | 更新日期即可 |

## 常見錯誤

### ❌ 內容重複
```markdown
錯誤：在 30-序列.md 中詳列 PC 交握的每個訊號定義
正確：30-序列.md 只寫「交握協議詳見 53.md」
```

### ❌ 過度技術化
```markdown
錯誤：「PointIndex := PointIndex + 1; IF PointIndex > MaxPoints THEN...」
正確：「移動至下一點位，所有點位完成後結束」
```

### ❌ 過度解釋
```markdown
錯誤：「為什麼需要這個功能：因為在作業模式下，允許操作員在特定時機...」
正確：「允許操作員在特定條件下進入防護區域」
```

### ❌ 隱含假設
```markdown
錯誤：「載台移動到位置」（哪個載台？什麼位置？）
正確：「Conv_Y1 移動至入料位置（Y=100mm）」
```
