# 光柵遮蔽功能定義

## 概述

本文件定義 PD20 設備的**光柵遮蔽（Light Curtain Mute）功能**，包括遮蔽條件、安全機制、STO 涉及軸定義等。

**設計原則**：
- 光柵遮蔽僅在作業模式下特定時機允許
- 三重 AND 條件確保安全
- STO 涉及軸暫停，其他軸繼續作業
- 遮蔽按鈕需持續按壓才生效

**相關文件**：
- 操作模式定義 → 參考 `12-operation-modes.md`
- 安全電路定義 → 參考 `41-safety-circuits.md`
- 記憶體映射 → 參考 `50-plc-memory-map.md`

---

## 光柵遮蔽功能說明

### 目的

**為什麼需要遮蔽**：
- 在作業模式下，允許操作員在特定時機進入光柵防護區域進行進出料操作
- 確保人員安全的前提下，提高作業效率
- 避免因光柵觸發而中斷整個設備運作

**設計理念**：
- 遮蔽不是「關閉」光柵，而是「允許人員進入」
- 光柵感測器仍在運作，只是不觸發停止
- 嚴格的條件控制確保安全

---

### 允許遮蔽的操作模式

| 操作模式 | 光柵遮蔽功能 | 說明 |
|---------|------------|------|
| 維修模式（0） | ❌ **禁止** | 維修模式下操作不可預期，禁止遮蔽確保人員安全 |
| 非作業模式（1） | ❌ 不需要 | 非作業模式下無自動序列，不需要遮蔽 |
| 作業模式（2） | ✅ **允許**（特定時機） | 正常作業時，特定時機允許遮蔽 |

---

## 三重 AND 遮蔽條件

### 遮蔽生效邏輯

```
光柵遮蔽生效 = 
    條件 1：PLC 判定允許遮蔽
    AND
    條件 2：軸在安全位置（硬體感測器確認）
    AND
    條件 3：操作員按下遮蔽按鈕（人工確認）
```

**三個條件必須同時滿足，缺一不可**

---

### 條件 1：PLC 判定允許遮蔽

**PLC 判定項目**：
- 操作模式 = 作業模式（OperationMode = 2）
- 設備狀態符合（參考時機定義）
- 相關載台工作結束
- 相關載台在安全區域

**入料區遮蔽 PLC 判定**：
- ✅ OperationMode = 2（作業模式）
- ✅ EquipmentState = 2（作業就緒）
- ✅ 載台1工作結束
- ✅ 載台1在安全區域（遠離入料口）

**出料區遮蔽 PLC 判定**：
- ✅ OperationMode = 2（作業模式）
- ✅ EquipmentState = 2（作業就緒）
- ✅ 出料Buffer有工件
- ✅ 載台2在安全區域（遠離出料口）

---

### 條件 2：軸在安全位置

**硬體感測器確認**：
- 由專用位置感測器確認
- **不可由軟體覆寫**
- 確保載台與天車實際位置安全

**入料區安全位置確認**：
```
載台1安全位置感測器 (In_____)
天車安全位置感測器 (In_____)

SafePosition_Input_OK = 
    Conv_Y1_PositionSensor (載台1遠離入料區)
    AND
    Conv_X_SafeZone (天車不在入料區上方)
```

**出料區安全位置確認**：
```
載台2安全位置感測器 (In_____)
天車安全位置感測器 (In_____)

SafePosition_Output_OK = 
    Conv_Y2_PositionSensor (載台2遠離出料區)
    AND
    Conv_X_SafeZone (天車不在出料區上方)
```

**記憶體位址**：
```
In_____ : BOOL;  // Conv_Y1_PositionSensor (載台1安全位置)
                 // [待填寫] → 填入 EXCEL

In_____ : BOOL;  // Conv_Y2_PositionSensor (載台2安全位置)
                 // [待填寫] → 填入 EXCEL

In_____ : BOOL;  // Conv_X_SafeZone (天車安全位置)
                 // [待填寫] → 填入 EXCEL
```

---

### 條件 3：操作員按下遮蔽按鈕

**按鈕特性**：
- 需**持續按壓**才生效
- 放開按鈕**立即解除遮蔽**
- 不可使用自鎖按鈕
- 需明顯標示「遮蔽」功能

**設計意義**：
- 操作員需持續按壓，確保專注操作
- 任何異常狀況可立即放開按鈕解除遮蔽
- 防止誤操作或忘記解除遮蔽

**記憶體位址**：
```
In_____ : BOOL;  // MuteButton_Input (入料區遮蔽按鈕)
                 // [待填寫] → 填入 EXCEL

In_____ : BOOL;  // MuteButton_Output (出料區遮蔽按鈕)
                 // [待填寫] → 填入 EXCEL
```

## 遮蔽允許時機

### 入料區光柵遮蔽時機

**允許時機**：
```
載台1作業流程：
1. 載台1檢測完成
2. 載台1移動至搬運位置（遠離入料口）
3. 天車搬運工件至載台2/開門模組
4. 載台1移動至等待區（遠離入料口）

↑ 在步驟 2~4 期間，載台1遠離入料口，允許入料區遮蔽
```

**關鍵條件**：
- 載台1不靠近入料口
- 天車不在入料區上方
- 入料Buffer無運動部件

**時機圖示**：
```
[入料區] ←─────── 載台1 ─────────→ [搬運區] ─────→ [等待區]
           (檢測中)        (安全位置，允許遮蔽)
```

---

### 出料區光柵遮蔽時機

**允許時機**：
```
出料流程：
1. 載台2/開門模組檢測完成
2. 天車搬運工件至出料Buffer
3. 出料Buffer上升（工件已放置）
4. 載台2在安全位置（遠離出料口）

↑ 在步驟 3~4 期間，出料Buffer有工件，允許出料區遮蔽
```

**關鍵條件**：
- 出料Buffer有工件等待取料
- 載台2不靠近出料口
- 天車不在出料區上方

**時機圖示**：
```
[載台2] ←─ 天車 ─→ [出料Buffer] ←─────── [出料區]
(安全位置)          (有工件，允許遮蔽)
```

## STO 涉及軸定義

### 概述

**STO（Safe Torque Off）**：
- 安全扭矩關閉
- 光柵遮蔽生效時，只有**可能危及人員的軸**需暫停
- 其他不涉及操作區域的軸可繼續作業

**設計優勢**：
- 提高生產效率（部分軸繼續作業）
- 確保人員安全（危險軸暫停）
- 減少遮蔽對產能的影響

---

### 入料區 STO 涉及軸

**需暫停的軸**（靠近入料區）：

| 軸名稱 | 說明 | 暫停原因 |
|--------|------|---------|
| Conv_Y1 | 載台1 Y軸 | 可能靠近入料口，危及操作員 |
| Conv_X | 天車 X軸 | 可能經過入料區上方 |
| InputBuffer_Z | 入料Buffer Z軸 | 直接在入料區動作 |

**繼續作業的軸**（遠離入料區）：

| 軸名稱 | 說明 | 繼續原因 |
|--------|------|---------|
| Conv_Y2 | 載台2 Y軸 | 遠離入料區，不危及操作員 |
| Conv_Y3 | 載台3 Y軸 | 遠離入料區，不危及操作員 |
| Conv_R1/R2/R3 | 載台旋轉軸 | 在載台本體，遠離入料區 |
| OutputBuffer_Z | 出料Buffer Z軸 | 在出料區，遠離入料區 |

**範例情境**：
```
入料區遮蔽生效時：
✅ 操作員在入料區放置工件
✅ 載台1暫停（遠離入料區）
✅ 天車暫停（不移動）
✅ 載台2/3繼續檢測作業（遠離入料區）
```

---

### 出料區 STO 涉及軸

**需暫停的軸**（靠近出料區）：

| 軸名稱 | 說明 | 暫停原因 |
|--------|------|---------|
| Conv_Y2 | 載台2 Y軸 | 可能靠近出料口，危及操作員 |
| Conv_X | 天車 X軸 | 可能經過出料區上方 |
| OutputBuffer_Z | 出料Buffer Z軸 | 直接在出料區動作 |

**繼續作業的軸**（遠離出料區）：

| 軸名稱 | 說明 | 繼續原因 |
|--------|------|---------|
| Conv_Y1 | 載台1 Y軸 | 遠離出料區，不危及操作員 |
| Conv_Y3 | 載台3 Y軸 | 遠離出料區，不危及操作員 |
| Conv_R1/R2/R3 | 載台旋轉軸 | 在載台本體，遠離出料區 |
| InputBuffer_Z | 入料Buffer Z軸 | 在入料區，遠離出料區 |

**範例情境**：
```
出料區遮蔽生效時：
✅ 操作員在出料區取走工件
✅ 載台2暫停（遠離出料區）
✅ 天車暫停（不移動）
✅ 載台1/3繼續檢測作業（遠離出料區）
```

---

## 安全位置參數定義

### 安全位置範圍

**載台1安全位置**（遠離入料區）：
```
SafePosition_Y1 = _____ mm  // [待填寫] → 填入 EXCEL

判定：Conv_Y1_Position > SafePosition_Y1
說明：載台1 Y 軸位置大於此值時，視為遠離入料區
```

**載台2安全位置**（遠離出料區）：
```
SafePosition_Y2 = _____ mm  // [待填寫] → 填入 EXCEL

判定：Conv_Y2_Position < SafePosition_Y2
說明：載台2 Y 軸位置小於此值時，視為遠離出料區
```

**天車安全位置範圍**：

## 遮蔽安全機制

### 遮蔽生效時

**光柵狀態**：
- 光柵感測器**仍在運作**（不是關閉）
- 只是允許人員進入而不觸發停止
- STO 涉及軸保持靜止（伺服 ON，但不移動）

**軸控制**：
- STO 涉及軸：伺服 ON，禁止移動指令
- 其他軸：正常運作，繼續序列

**人員保護**：
- 遮蔽按鈕需持續按壓
- 放開按鈕立即解除遮蔽
- 操作員需全程監控

---

### 遮蔽失效時機

**立即解除遮蔽**：
- ✅ 遮蔽按鈕放開
- ✅ 軸開始移動（STO 涉及軸）
- ✅ 載台移動離開安全位置
- ✅ 切換操作模式
- ✅ 設備狀態變更
- ✅ 異常發生

**解除遮蔽後**：
- 光柵恢復正常防護功能
- 若人員仍在光柵區域 → 觸發停止
- STO 涉及軸可恢復移動

---

### 遮蔽失效邏輯

**任一條件失效，遮蔽立即解除**：
```
MuteActive_Input = 
    PLC_Allow_Input_Mute
    AND
    SafePosition_Input_OK
    AND
    MuteButton_Input
    
若任一項 = FALSE → MuteActive_Input = FALSE
```

### 遮蔽判定邏輯概要

**入料區遮蔽判定**：
1. 檢查操作模式 = 2（作業模式）
2. 檢查設備狀態 = 2（作業就緒）
3. 檢查載台1工作結束
4. 檢查載台1安全位置感測器
5. 檢查天車安全位置感測器
6. 檢查遮蔽按鈕按下
7. 全部 OK → MuteActive_Input = TRUE

**出料區遮蔽判定**：
1. 檢查操作模式 = 2（作業模式）
2. 檢查設備狀態 = 2（作業就緒）
3. 檢查出料Buffer有工件
4. 檢查載台2安全位置感測器
5. 檢查天車安全位置感測器
6. 檢查遮蔽按鈕按下
7. 全部 OK → MuteActive_Output = TRUE

---

### STO 軸控制邏輯概要

**入料區遮蔽生效時**：
```
IF MuteActive_Input THEN
    Conv_Y1_STO := TRUE;        // 載台1暫停
    Conv_X_STO := TRUE;         // 天車暫停
    InputBuffer_Z_STO := TRUE;  // 入料Buffer暫停
ELSE
    Conv_Y1_STO := FALSE;
    Conv_X_STO := FALSE;
    InputBuffer_Z_STO := FALSE;
END_IF;
```

**出料區遮蔽生效時**：
```
IF MuteActive_Output THEN
    Conv_Y2_STO := TRUE;         // 載台2暫停
    Conv_X_STO := TRUE;          // 天車暫停
    OutputBuffer_Z_STO := TRUE;  // 出料Buffer暫停
ELSE
    Conv_Y2_STO := FALSE;
    Conv_X_STO := FALSE;
    OutputBuffer_Z_STO := FALSE;
END_IF;
```

**注意**：
- Conv_X_STO（天車）在入料或出料遮蔽時都需暫停
- 邏輯需考慮兩者同時發生的情況

## PC 使用指引

### PC 監控項目

**PC 應監控**：
- MuteFunctionEnabled（MR_____）- 遮蔽功能是否啟用
- MuteActive_Input（MR_____）- 入料區遮蔽是否生效
- MuteActive_Output（MR_____）- 出料區遮蔽是否生效

**顯示建議**：
- 遮蔽功能啟用時，顯示「光柵遮蔽可用」
- 遮蔽生效時，顯示「⚠️ 入料區/出料區遮蔽中」
- 提示操作員注意安全

## 操作指引

### 入料區遮蔽操作步驟

```
1. 確認設備在作業模式（OperationMode = 2）
   ↓
2. 確認載台1已完成工作且在安全位置
   ↓
3. 準備工件
   ↓
4. 按住入料區遮蔽按鈕
   ↓
5. 確認遮蔽生效（指示燈亮起或 PC 顯示）
   ↓
6. 進入入料區放置工件
   ↓
7. 退出入料區
   ↓
8. 放開遮蔽按鈕
   ↓
9. 確認遮蔽解除
```

---

### 出料區遮蔽操作步驟

```
1. 確認設備在作業模式（OperationMode = 2）
   ↓
2. 確認出料Buffer有工件
   ↓
3. 按住出料區遮蔽按鈕
   ↓
4. 確認遮蔽生效（指示燈亮起或 PC 顯示）
   ↓
5. 進入出料區取走工件
   ↓
6. 退出出料區
   ↓
7. 放開遮蔽按鈕
   ↓
8. 確認遮蔽解除
```

## 注意事項

### 安全注意事項
- ⚠️ **遮蔽按鈕必須持續按壓**，放開立即解除
- ⚠️ 遮蔽生效時需全程監控設備
- ⚠️ 維修模式下**禁止**使用遮蔽功能
- ⚠️ 遮蔽時 STO 涉及軸會暫停，其他軸繼續作業，注意避讓

### 操作注意事項
- 💡 進入遮蔽區域前確認遮蔽生效
- 💡 操作完畢立即退出並放開按鈕
- 💡 若遮蔽失效，光柵立即恢復防護
- 💡 不可使用自鎖按鈕或固定按鈕

### 維護注意事項
- 💡 定期測試遮蔽功能是否正常
- 💡 定期檢查安全位置感測器
- 💡 確認遮蔽按鈕機械特性正常
- 💡 記錄遮蔽使用頻率與異常
