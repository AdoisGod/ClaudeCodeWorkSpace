# 52. 數據緩衝區（Zone）

**文件版本**: v3.0  
**最後更新**: 2025-12-12  
**目標讀者**: PC 開發團隊

---

## 1. 概述

本文件定義 PLC 與 PC 之間的數據交換緩衝區架構，採用四區循環緩衝（Ring Buffer）確保數據傳輸可靠性。

### 設計原則

- 四個獨立緩衝區循環使用，每區對應一個產品
- 產品進站時建立 Zone，出站時清除
- PLC 寫入量測數據，PC 讀取處理

| Zone | 起始位址 | 結束位址 | 容量 |

| Zone 4 | DM5900 | DM6199 | 300 words |

### 2.2 各工位 Zone 編號追蹤

PLC 在以下位址告知 PC 各工位當前使用的 Zone 編號：

| 位址 | 工位 | 說明 |
|------|------|------|
| DM90 | 入料 Buffer | 入料時分配的 Zone 編號（1~4）|
| DM92 | 載台1 | 載台1 當前產品的 Zone 編號 |
| DM94 | 載台2 | 載台2 當前產品的 Zone 編號 |
| DM96 | 載台3 | 載台3 當前產品的 Zone 編號 |
| DM98 | 出料 Buffer | 出料產品的 Zone 編號 |

> **重要**：Zone 編號**跟隨產品移動**。產品從載台1 搬運到載台2 時，Zone 編號不變，僅工位追蹤位址更新。

### 2.3 Zone 生命週期

```
入料 Buffer          載台1          載台2          載台3          出料 Buffer
    |                  |              |              |                |
 分配 Zone N -----> DM92=N -----> DM94=N -----> DM96=N -----> DM98=N
 (DM90=N)            |              |              |                |
    |             量測寫入       量測寫入       量測寫入          |
    |                  |              |              |          DataReady
    |                  |              |              |          PC 讀取
    |                  |              |              |          清空 Zone
```

## 6. 交握協議

### 觸發時機

DataReady 在**產品到達出料 Buffer** 時觸發，此時所有量測數據已寫入完成。

```
產品流程                          Zone 數據狀態
   |                                   |
入料 → 分配 Zone N                   建立 Zone
   |                                   |
載台1 檢測 → 寫入量測數據            累積數據
   |                                   |
載台2 檢測 → 寫入量測數據            累積數據
   |                                   |
載台3 檢測 → 寫入量測數據            累積數據
   |                                   |
到達出料 Buffer                      DataReady ON
   |                                   |
PC 讀取完成                          ReadDone ON → 清空 Zone
```

### 時序

```
PLC                           PC
 |                             |
 |-- 產品到達出料 Buffer ----->|
 |-- 狀態=2 (待讀取) --------->|
 |-- DataReady ON ------------>|
 |                             |-- 檢測到 DataReady
 |                             |-- 從 DM98 取得 Zone 編號
 |                             |-- 讀取對應 Zone 數據
 |<-- ReadDone ON -------------|
 |-- 清空 ZoneN -------------->|
 |-- 狀態=0 (空閒) ----------->|
 |-- DataReady OFF ----------->|（PLC 清除）
 |-- ReadDone OFF ------------>|（PLC 清除）
 |                             |
```

> **重要**：所有訊號的 OFF 狀態皆由 **PLC 主動清除**，PC 僅負責接收 DataReady 並發出 ReadDone。

### PC 端實作要點

1. **監控訊號**: 持續監控 MR1000/1002/1004/1006
2. **取得 Zone 編號**: 從 DM98（出料 Buffer）讀取 Zone 編號
3. **計算位址**: Zone 基底 = 5000 + (N-1) × 300
4. **讀取數據**: 讀取對應 Zone 的 300 words
5. **回應完成**: 讀取完成後設定 ReadDone=1
6. **不做清除**: PC 不清除任何訊號，由 PLC 統一管理

## 8. 初始化

### 原點復歸時執行

1. 清空所有緩衝區（DM5000~6199）
2. 重置狀態旗標（DM30060~30067 = 0）
3. 清空握手訊號（MR1000~1007 = OFF）

---

## 9. 錯誤處理

### Timeout 建議

| 項目 | 建議值 |
|------|-------|
| PC 讀取 | 30 秒 |
| Zone 佔用 | 60 秒 |

### 溢位處理

若四個 Zone 全滿，PLC 將觸發警報並等待。
