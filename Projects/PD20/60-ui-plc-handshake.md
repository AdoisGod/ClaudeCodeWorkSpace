## 1. 概述

本文件定義 PC2 (HMI/UI) 與 PLC 之間的交握訊號，涵蓋各功能頁面的控制與監控點位。

**交握類型說明**：
| ActionType | 說明 |
|------------|------|
| A | 單次動作（按下觸發） |
| B | 執行動作（需等待完成） |
| C | 持續動作（Jog，按住執行） |

## 10. 應用場景

### 10.1 Buffer 氣缸手動操作（故障排查用）

當 Buffer 氣缸卡住時，可透過以下步驟手動操作：

1. **確認設備狀態**：MR5600 = TRUE（PM 維護模式）
2. **入料Buffer操作**：
   - 上升：設定 MR901 = TRUE
   - 下降：設定 MR900 = TRUE
3. **出料Buffer操作**：
   - 上升：設定 MR903 = TRUE
   - 下降：設定 MR904 = TRUE

### 10.2 載台定位氣缸手動操作

1. **載台1**：
   - 固定：MR1811 = TRUE
   - 鬆開：MR1810 = TRUE
   - 確認狀態：MR1900（鬆開位置）/ MR1901（固定位置）
2. **載台2**：
   - 固定：MR1813 = TRUE
   - 鬆開：MR1812 = TRUE
   - 確認狀態：MR1902（鬆開位置）/ MR1903（固定位置）
