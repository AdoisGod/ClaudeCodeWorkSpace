# 軸規格定義

## 說明

本設備共有 **27 個運動軸**，包含伺服馬達、DD 馬達、步進馬達三種類型。
本文件記錄所有軸的基本規格和配置資訊。

## 詳細規格（主要軸）

### Conv_Y1 / Conv_Y2 - 產品輸送Y軸

#### 基本規格
- **馬達類型**: 伺服馬達
- **驅動器**: MCDLT35BF
- **煞車**: 無
- **Conv_Y1_行程**: [-94~894] mm
- **Conv_Y2_行程**: [-38~885] mm
- **最大速度**: [待填寫] mm/s
- **建議速度**: [300] mm/s

#### 用途
產品在輸送線上的 Y 方向移動

#### 安全迴路
- Conv_Y1: 安全迴路 3
- Conv_Y2: 安全迴路 4

#### 關鍵位置
| 位置名稱 | 座標 (mm) | 用途 |
|---------|-----------|------|
| POS_CONV_Y1_HOME | [待填寫] | 原點 |
| POS_CONV_Y1_LOAD | [待填寫] | 上料位置 |
| POS_CONV_Y1_UNLOAD | [待填寫] | 下料位置 |

---

### Conv_R1 / Conv_R2 - 產品旋轉軸

#### 基本規格
- **馬達類型**: DD 馬達（直驅馬達）
- **驅動器**: BA1SGDXS-120AA0A0002
- **煞車**: 無
- **旋轉範圍**: [待填寫] 度（例如：0-360°）
- **最大速度**: [待填寫] °/s
- **定位精度**: ±[待填寫] 度

#### 用途
產品旋轉定位，用於不同角度的檢測

#### 安全迴路
- Conv_R1: 安全迴路 3
- Conv_R2: 安全迴路 4

#### 關鍵位置
| 位置名稱 | 角度 (度) | 用途 |
|---------|----------|------|
| POS_CONV_R1_HOME | 0 | 原點 |

| POS_CONV_R1_ANGLE_90 | 90 | 側面檢測 |
| POS_CONV_R1_ANGLE_180 | 180 | 背面檢測 |

### Conv_Z - 搬運天車Z軸

#### 基本規格
- **馬達類型**: 伺服馬達
- **驅動器**: MBDLT25BF
- **煞車**: 有
- **行程**: [待填寫] mm
- **用途**: 天車升降，用於工件搬運

#### 相關軸
- **Conv_X**: 天車 X 方向移動
- **Conv_Z**: 天車 Z 方向移動（本軸）

#### 關鍵位置
| 位置名稱 | 座標 (mm) | 用途 |
|---------|-----------|------|
| POS_CONV_Z_UP | [待填寫] | 上限位（運輸高度） |
| POS_CONV_Z_DOWN | [待填寫] | 下限位（夾取高度） |

---

### Vis_Z / Vis_X - 鑰匙孔相機軸

#### 基本規格
- **馬達類型**: 伺服馬達
- **驅動器**: MBDLT25BF
- **煞車**: Vis_Z 有煞車，Vis_X 無煞車
- **用途**: 鑰匙孔視覺檢測用相機的定位

#### 軸說明
- **Vis_Z**: 相機上下移動（對焦高度調整）
- **Vis_X**: 相機對焦（前後移動）

---

### Slot_Z / Solt_X - Slot 相機軸

#### 基本規格
- **馬達類型**: 伺服馬達
- **驅動器**: MBDLT25BF
- **煞車**: Slot_Z 有煞車，Solt_X 無煞車
- **用途**: Slot 檢測用相機的定位

#### 軸說明
- **Slot_Z**: 相機上下移動（檢測高度）
- **Solt_X**: 相機伸入/收回（進入 Slot 內部拍照）

#### 特別說明
Slot_Z 是 **Slot 拍照 Trigger 軸**，到達指定位置時觸發拍照。

#### 安全迴路
- Slot_Z: 安全迴路 4
- Solt_X: 安全迴路 3

## 命名規則

### 軸名稱格式
```
[功能區]_[方向/編號]

範例：
- Conv_Y1：輸送(Conv) - Y方向 - 編號1
- Vis_Z：視覺(Vis) - Z方向
- Handle_3：手把(Handle) - 編號3
```

### 位置常數命名
```
格式：POS_[軸名]_[位置名]

範例：
- POS_CONV_Y1_HOME
- POS_VIS_Z_FOCUS
- POS_DOOR_X_OPEN
```

## 使用建議

### 查詢軸資訊
```
需要知道某個軸的資訊？
→ 在本文件搜尋軸名稱
→ 查看詳細規格表
```

### 設計動作流程
```
涉及某個功能區？
→ 查看功能分類表
→ 確認需要哪幾個軸配合
→ 參考詳細規格設計動作
```

### 安全考量
```
設計動作時：
→ 檢查是否有煞車
→ 檢查是否在安全迴路內
→ 垂直軸必須考慮失電保護
```
