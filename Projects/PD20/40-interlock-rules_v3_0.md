## 說明

本文件定義 PD20 設備所有互鎖規則，確保設備安全運行。
互鎖規則是**強制性的安全條件**，任何動作執行前必須檢查對應的互鎖條件。

**文件範圍**：
- 軸與軸之間的互鎖
- 軸與氣缸之間的互鎖
- 軸與感測器之間的互鎖
- 氣缸與感測器之間的互鎖
- 安全迴路相關互鎖

**注意事項**：
- 所有互鎖條件必須在 PLC 程式中實現
- 違反互鎖條件時必須觸發異常並停止動作
- 安全迴路的詳細硬體配置請參考 `41-safety-circuits.md`

## PLC 記憶體位置分類

| 記憶體區段 | 用途說明 | 範例 |
|-----------|---------|------|
| R0XX (R003~R099) | 主要運動軸的移動限制與互鎖 | Conv_R1/R2/Y1/Y2, Conv_X/Z, Valve_X |
| R1XX (R112) | 開門模組軸互鎖 | Door_X |
| R3XX (R301~R399) | 載台、Buffer區、禁區相關互鎖 | 入料/出料Buffer, 禁區管制, 原點狀態 |
| R4XX (R402~R499) | 開門模組、檢測軸相關互鎖 | Door_X, DCheck_R1/R2, Slot_X, Inner_X, SLight_X |
| R5XX (預留) | 氣缸控制相關互鎖 | 定位氣缸、夾料氣缸等 |
| R6XX (預留) | 感測器狀態監控與異常 | 工件在席監控、感測器異常 |
| R7XX (預留) | 安全迴路與急停相關 | 安全光柵、急停按鈕 |

# 2. 軸與氣缸的互鎖

## 2.1 天車氣缸互鎖

### 天車X氣缸與夾料氣缸互鎖

**規則描述**：天車X氣缸（左右撐開）只能在夾料氣缸鬆開狀態下動作

| 動作 | 前置條件 | 感測器狀態 |
|------|---------|-----------|
| 撐開（Out606=TRUE） | 夾料氣缸已解除 | In206 AND In207 = TRUE |
| 縮回（Out607=TRUE） | 夾料氣缸已解除 | In206 AND In207 = TRUE |

**禁止**：夾料氣缸鎖定時（In204 AND In205 = TRUE），天車X氣缸動作

---

### 天車X氣缸與工件狀態互鎖

**規則描述**：天車X氣缸狀態必須與工件夾持狀態一致

| 工件狀態 | 天車X氣缸要求狀態 | 感測器 |
|---------|----------------|--------|
| 有夾持工件 | 撐開（上位） | In202 = TRUE |
| 無夾持工件 | 縮回（下位） | In203 = TRUE |

**相關序列**：SEQ-003

---

## 2.2 定位氣缸互鎖

### 載台1定位氣缸互鎖

**規則描述**：載台1定位氣缸只能在特定作業階段，且 Conv_Y1 在指定位置時動作

| 動作 | 前置條件 | 感測器狀態 |
|------|---------|-----------|
| 伸出（鎖定） | Conv_Y1 在搬運位置且到位 | In100 = TRUE |
| 縮回（解除） | Conv_Y1 在入料位置且到位 | In101 = TRUE |

---

### 載台2定位氣缸互鎖

**規則描述**：載台2定位氣缸只能在特定作業階段，且 Conv_Y2 在指定位置時動作

| 動作 | 前置條件 | 感測器狀態 |
|------|---------|-----------|
| 伸出（鎖定） | Conv_Y2 在搬運位置且到位 | In102 = TRUE |
| 縮回（解除） | Conv_Y2 在出料位置且到位 | In103 = TRUE |

---

## 2.3 Buffer氣缸互鎖

### 入料Buffer氣缸互鎖

**規則描述**：入料Buffer氣缸只能在安全條件下動作

| 動作 | 前置條件 |
|------|---------|
| 上升 | 載台1無工件（In010/011/012 = FALSE） |
| 下降 | Conv_Y1 在入料位置且到位 |

**完成條件**：
- 上升：In112 AND In113 AND In114 = TRUE
- 下降：In304 AND In305 AND In306 = TRUE

---

### 出料Buffer氣缸互鎖

**規則描述**：出料Buffer氣缸只能在安全條件下動作

| 動作 | 前置條件 |
|------|---------|
| 上升 | Conv_Y2 在出料位置且到位 |
| 下降 | 出料Buffer區無工件 |

**完成條件**：
- 上升：In115 AND In200 AND In201 = TRUE
- 下降：In307 AND In308 AND In309 = TRUE
