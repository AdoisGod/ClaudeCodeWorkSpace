## 2. 入料控制

### 2.1 入料交握訊號

| 位址 | 方向 | 說明 |
|------|------|------|
| MR908 | PLC→PC | 入料通知（工件已到達入料緩衝區）|
| MR909 | PC→PLC | RFID 讀取完成，允許 PLC 執行入料動作 |

### 2.2 入料條件

PLC 發送入料通知（MR908）的前提：
- 入料緩衝區有工件（In110 = TRUE）
- 入料 Buffer 氣缸在上位（In112/113/114 = TRUE）
- 載台1 無工件（In010/011/012 = FALSE）

PC 回覆 MR909 前須完成：
- 讀取工件 RFID
- 從 DM90 取得 PLC 分配的 Zone 編號
- 將 RFID 資料寫入對應 Zone（DM5000+offset 或對應 Zone 基底）

### 2.3 交握時序

```
PLC                           PC
 |                             |
 |-- 工件到達入料緩衝區 ------>|
 |-- MR908 ON ---------------->|（通知 PC 入料）
 |                             |-- 讀取 RFID
 |                             |-- 建立 Zone 資料
 |<-- MR909 ON ----------------|（RFID 完成，允許作業）
 |-- 執行入料動作 ------------>|
 |-- 入料完成 ---------------->|
 |-- MR908 OFF --------------->|（PLC 清除）
 |-- MR909 OFF --------------->|（PLC 清除）
 |                             |
```

> **重要**：所有訊號的 OFF 狀態皆由 **PLC 主動清除**，PC 僅負責接收 MR908 並發出 MR909。
>
> 詳細入料動作步驟請參考 31-motion-sequences-common.md（SEQ-001）

## 4. 流程狀態

### 4.1 當前階段

| 位址 | 說明 |
|------|------|
| DM19020 | 當前流程階段代碼 |

| 代碼 | 說明 |
|------|------|
| 0 | 待機 |
| 1 | 入料中 |
| 2 | 載台1檢測中 |
| 3 | 搬運至載台2 |
| 4 | 開門作業（載台2+3協作）|
| 5 | 載台2+3同時檢測中 |
| 6 | 關門作業（載台2+3協作）|
| 7 | 出料中 |

> **說明**：開門後，載台2（SEQ-201~203）與載台3（SEQ-303~304）同時進行檢測，兩者皆完成後才執行關門。

### 4.2 進度指示

| 位址 | 說明 |
|------|------|
| DM19022 | 當前序列編號 |
| DM19024 | 當前序列進度（%）|
