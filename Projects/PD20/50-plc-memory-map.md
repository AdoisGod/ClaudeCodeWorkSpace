## 5. 維護指引

### 新增訊號流程

1. **確認區域**: 根據訊號功能查找對應區域（MR1100~1399 = 拍照握手）
2. **檢查衝突**: 掃描該區域表格，確認位址未被使用
3. **更新 50.md**: 在對應區域表格新增一行
4. **更新詳細文檔**: 跳轉到「詳見」欄位指定的文件（如 51.md）
5. **同步 Excel**: 使用 `nico-pd20-ui-bridge` skill 同步

### 從工作紀錄維護

```
工作紀錄: 新增 MR1124: SEQ-105_Trigger
↓
查 50.md § MR1100~1399
↓
確認 MR1124 未使用
↓
更新 50.md（新增 MR1124 行）
更新 51.md（新增 SEQ-105 詳細協議）
更新 Excel（同步）
```

### 從 Excel 維護

```
Excel 新增: MR2500 | Door_Z_Jog+
↓
查 50.md § MR2000~2999
↓
更新 50.md（新增 MR2500 行）
更新 55.md（新增軸控制規格）
```

### 衝突檢查

使用 `nico-pd20-ui-bridge` skill:
```
「檢查 Excel 和 Markdown 的一致性」
```
