# 53. 設備狀態介面

**文件版本**: v2.1
**最後更新**: 2025-12-13
**目標讀者**: PC 開發團隊
**資料來源**: PD20_Automaton_PLC交握表_vol1_1212.xlsx

---

## 1. 概述

本文件定義 PC 讀取設備狀態的介面，包含設備運行狀態、安全狀態、軸狀態等。

### 讀取方式

所有狀態為**唯讀**，PC 定期輪詢或事件觸發讀取。

---

## 2. 設備運行狀態

### 2.1 主狀態（MR5600~5603）

| 位址 | 狀態 | 說明 |
|------|------|------|
| MR5600 | PM | 維護模式 |
| MR5601 | IDLE | 待機中 |
| MR5602 | RUN | 運行中 |
| MR5603 | DOWN | 停機（異常）|

> 同一時間僅一個狀態為 ON

### 2.2 子狀態（DM19000）

| 數值 | 說明 |
|------|------|
| 0 | 無子狀態 |
| 1 | 原點復歸中 |
| 2 | 等待入料 |
| 3 | 檢測中 |
| 4 | 等待出料 |
| 5 | 警報處理中 |

## 5. 軸狀態

### 5.1 軸狀態區（MR5000~5999）

每軸佔用 10 個連續 MR：

| 偏移 | 說明 |
|------|------|
| +0 | 原點完成 |
| +1 | 移動中 |
| +2 | 到位 |
| +3 | 錯誤 |
| +4 | 正極限 |
| +5 | 負極限 |
| +6~9 | 保留 |

### 5.2 軸編號對應

| 軸 | 起始位址 |
|----|---------|
| Conv_X | MR5000 |
| Conv_Y1 | MR5010 |
| Conv_Y2 | MR5020 |
| Conv_Z | MR5030 |
| Vis_X | MR5040 |
| Vis_Z | MR5050 |
| ... | ... |

> 完整對應表見 56.md

### 5.3 軸當前座標（DM6200~6399）
