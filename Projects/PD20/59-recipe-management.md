## 5. 料號操作

### 5.1 讀寫命令

| 位址 | 方向 | 說明 |
|------|------|------|
| DM19040 | PC→PLC | 目標料號編號（1~20）|
| MR960 | PC→PLC | 載入料號 |
| MR961 | PC→PLC | 儲存料號 |
| MR962 | PLC→PC | 操作完成 |
| MR963 | PLC→PC | 操作失敗 |

### 5.2 操作流程

**載入料號**：
```
1. 設定 DM19040 = 料號編號
2. MR960 = ON
3. 等待 MR962 = ON
4. 從 DM20000+ 讀取參數
```

**儲存料號**：
```
1. 設定 DM19040 = 料號編號
2. 寫入參數到 DM20000+
3. MR961 = ON
4. 等待 MR962 = ON
```
