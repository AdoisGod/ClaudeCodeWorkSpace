# 設備概述

## 基本資訊

### 設備識別
- **設備名稱**: 自動化視覺檢測設備
- **設備編號**: PD20
- **設備類型**: 半導體 Foup 門板視覺檢測設備
- **檢測對象**: Foup (Front Opening Unified Pod) 門板

### 設備用途
- Foup 門板的自動化視覺檢測
- 多站點缺陷檢測、尺寸量測
- 手把、鑰匙孔、膠條、Latch等部位檢測
- 開關門扭力量測
- Slot內部檢測

## 系統架構

### 控制架構圖
```
┌─────────┐
│   PLC   │ ← 你負責 (Keyence KV-XL系列)
│ 動作控制 │   - 27軸運動控制
│ 量測控制 │   - 8組氣缸控制
│ 安全互鎖 │   - 4組安全迴路監控
└─────────┘
      │
      ├───────────────┐
      │               │
      ▼               ▼
┌─────────┐     ┌─────────┐
│  PC1    │     │  PC2    │
│視覺處理  │     │  HMI    │
│ -相機控制│     │ -操作介面│
│ -影像處理│     │ -參數設定│
│ -判定邏輯│     │ -資料顯示│
└─────────┘     └─────────┘
      │               │
      └───────┬───────┘
              │
    (主動讀取PLC記憶體)
```

### 通訊協議
- **PLC ↔ PC1/PC2**: TCP/IP
- **PLC ↔ 驅動器**: EtherCAT
- **開門模組 ↔ PLC**: RS485 (扭力數據)
- **PC主動輪詢**: 100~500ms週期讀取MR/DM

## 控制分工

### PLC 職責範圍

#### ✅ 動作控制
- 27軸運動軌跡控制
- 8組氣缸時序控制
- 14個檢測序列協調執行
- 天車搬運路徑規劃
- 開門模組動作控制

#### ✅ 設備狀態管理
- 5種設備狀態管理 (OFFLINE/IDLE/EXECUTING/PAUSED/ERROR)
- 狀態轉換邏輯控制
- 狀態值寫入記憶體 (供PC2讀取)

#### ✅ 量測數據暫存
- 量測數據寫入DM5000~6199 (4個獨立位置)
- 各軸當前狀態寫入DM6200~6315
- 料號參數管理 (DM20000~20999)
- 數據讀取位置控制 (MR1000~1007)

#### ✅ 流程節點告知
- MR握手訊號管理 (MR1100~1307)
- 序列執行狀態通知
- 軸到位訊號觸發
- Trigger/Done訊號協調

#### ✅ 安全互鎖
- 4組安全迴路監控
  - 迴路1: 門檢+E-Stop → 主迴路MC
  - 迴路3: 入料光柵 → Conv_Y1/R1 + Slot_X STO
  - 迴路4: 出料光柵 → Conv_Y2/R2 + Slot_Z STO
- 軸群互鎖規則執行
- 極限訊號監控 (MR5000~5506)

### PC1 職責 (視覺處理)
- 相機觸發與拍照
- 影像處理演算法執行
- 視覺判定邏輯
- **主動讀取PLC的MR/DM** (不是PLC推送)
- 量測數據讀取與記錄 (DM5000~6199)

### PC2 職責 (HMI)
- 操作介面顯示
- 參數設定與下載
- 即時資料顯示
- 歷史記錄查詢
- **主動讀取PLC狀態和數據** (不是PLC推送)
- 設備狀態監控 (讀取EquipmentState)

## 作業模式

### 全自動模式
- **特點**: 使用OHT (Overhead Hoist Transport) 進出料
- **流程**: OHT送料 → 自動檢測 → OHT收料
- **需求**: 與OHT系統整合通訊
- **光柵**: 正常運作，不使用遮蔽功能

### 半自動模式
- **特點**: 人工進出料，自動檢測
- **流程**: 人工上料 → 自動檢測 → 人工下料
- **需求**: 無須OHT整合
- **光柵**: 可使用遮蔽功能，配合三重條件AND邏輯
  - 條件1: 設備狀態允許
  - 條件2: 相關軸在安全位置
  - 條件3: 操作人員按下遮蔽按鈕 (In310/In311)

### 手動模式
- **特點**: 手動控制，用於測試與維護
- **功能**: 
  - 可手動控制各軸移動
  - 可手動控制氣缸動作
  - 不執行自動檢測序列
  - 可單獨測試各功能模組
- **用途**: 設備調試、故障排除、維護保養

## 安全系統架構

### 4組安全迴路

| 迴路 | 監控對象 | 控制目標 | 作動方式 | 狀態 |
|------|---------|---------|---------|------|
| 迴路1 | 門檢 + E-Stop | 主迴路MC (全軸) | 切斷驅動器電源 | ✅使用中 |
| 迴路2 | (已淘汰) | - | - | ❌已淘汰 |
| 迴路3 | 入料區光柵 | Conv_Y1/R1 + Slot_X | STO觸發 | ✅使用中 |
| 迴路4 | 出料區光柵 | Conv_Y2/R2 + Slot_Z | STO觸發 | ✅使用中 |

### 安全等級
- **Critical**: 迴路1 (切斷所有動力)
- **High**: 迴路3/4 (STO特定軸)

### 光柵遮蔽機制 (半自動模式)
- 三重條件AND邏輯
  1. 設備狀態允許 (PLC判定)
  2. 軸在安全位置 (硬體感測器確認)
  3. 操作員按下遮蔽按鈕 (In310或In311)
- 硬體層級保護，不經PLC
- 作業完成後自動恢復光柵保護
