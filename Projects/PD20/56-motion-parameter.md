## 3. 軸參數設定

### 3.1 通用參數區（DM100~299）

每軸佔用 6 words：

| 偏移 | 說明 | 型態 |
|------|------|------|
| +0 | 最大速度 | REAL32 |
| +2 | 加速度 | REAL32 |
| +4 | 減速度 | REAL32 |

### 3.2 軸參數讀寫

| 位址 | 方向 | 說明 |
|------|------|------|
| DM700 | PC→PLC | 目標軸編號 |
| MR100 | PC→PLC | 軸參數寫入 |
| MR101 | PC→PLC | 軸參數讀取 |

### 3.3 讀寫流程

**寫入流程**：
```
1. 設定 DM700 = 軸編號
2. 設定 DM100~105（該軸參數區）
3. MR100 = ON
4. 等待 MR100 自動復位
```

**讀取流程**：
```
1. 設定 DM700 = 軸編號
2. MR101 = ON
3. 等待 MR101 自動復位
4. 讀取 DM100~105
```
