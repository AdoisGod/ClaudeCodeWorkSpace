# 0. 原點復歸序列

## SEQ-000: 原點復歸流程

### 功能
執行設備所有軸與氣缸的原點復歸動作，確保設備位置正確。

### 前置條件
- [ ] 設備在**非作業模式**（OperationMode = 0 或 1）
- [ ] 載台1 無工件（In010/In011/In012 = FALSE）
- [ ] 載台2 無工件（In013/In014/In015 = FALSE）
- [ ] 載台3 無工件（In208/In209 = FALSE）
- [ ] 無嚴重警報（EquipmentAlarm = FALSE）
- [ ] 操作員已確認安全

### 涉及元件
- **所有軸**：29 軸
- **所有氣缸**：入料/出料 Buffer、載台定位、天車、開門模組
- **感測器**：各軸原點感測器、氣缸位置感測器

---

### 動作步驟（分組復歸）

#### 第一組：特定軸優先復歸（依賴關係）

| Step | 動作描述 | 涉及軸 | 完成條件 | 備註 |
|------|---------|--------|---------|------|
| 1.1 | Valve_X 原點復歸 | Valve_X | Valve_X 原點完成且停在原點上 | **必須先完成** |
| 1.2 | DCheck_R1/R2 原點復歸 | DCheck_R1, DCheck_R2 | 兩軸原點完成 | **必須先完成** |

**關鍵依賴**：
```
Valve_X 完成 → Conv_Y1 才能移動
DCheck_R1/R2 完成 → Door_X 才能移動到指定位置
```

---

#### 第二組：Door_X 移動

| Step | 動作描述 | 涉及軸 | 完成條件 | 依賴條件 |
|------|---------|--------|---------|---------|
| 2.1 | Door_X 原點復歸 | Door_X | Door_X 原點完成 | 等待 DCheck_R1/R2 完成 |
| 2.2 | Door_X 移動到指定位置 | Door_X | Door_X 到達指定位置 | 原點完成後移動 |

**說明**：Door_X 在原點上須等到 DCheck_R1/DCheck_R2 回原點結束後才能移動到指定位置

---

#### 第三組：載台 Y 軸復歸（等待 Door_X）

| Step | 動作描述 | 涉及軸 | 完成條件 | 依賴條件 |
|------|---------|--------|---------|---------|
| 3.1 | Conv_Y1 原點復歸 | Conv_Y1 | Conv_Y1 原點完成 | 等待 Door_X 到達指定位置 |
| 3.2 | Conv_Y2 原點復歸 | Conv_Y2 | Conv_Y2 原點完成 | 等待 Door_X 到達指定位置 |

**關鍵依賴**：
```
Conv_Y1/Y2 須等到 Door_X 回到原點並移動到指定位置後才能復歸
```

---

#### 第四組：載台 Y 軸移動到旋轉工作位置

| Step | 動作描述 | 涉及軸 | 完成條件 | 備註 |
|------|---------|--------|---------|------|
| 4.1 | Conv_Y1 移動到旋轉工作位置 | Conv_Y1 | Conv_Y1 到達旋轉工作位置 | 原點完成後移動 |
| 4.2 | Conv_Y2 移動到旋轉工作位置 | Conv_Y2 | Conv_Y2 到達旋轉工作位置 | 原點完成後移動 |

**說明**：Conv_Y1/Y2 回到原點後會移動到各自的旋轉工作位置

---

#### 第五組：載台 R 軸復歸（等待 Y 軸到位）

| Step | 動作描述 | 涉及軸 | 完成條件 | 依賴條件 |
|------|---------|--------|---------|---------|
| 5.1 | Conv_R1 原點復歸 | Conv_R1 | Conv_R1 原點完成（0度） | 等待 Conv_Y1 到達旋轉工作位置 |
| 5.2 | Conv_R2 原點復歸 | Conv_R2 | Conv_R2 原點完成（0度） | 等待 Conv_Y2 到達旋轉工作位置 |

**關鍵依賴**：
```
到了旋轉工作位置後才能進行 Conv_R1/R2 的原點復歸
```

---

#### 第六組：其餘軸原點復歸（無依賴關係，並行執行）

| Step | 動作描述 | 涉及軸 | 完成條件 | 備註 |
|------|---------|--------|---------|------|
| 6.1 | 天車系統原點復歸 | Conv_X, Conv_Z | 兩軸原點完成 | 並行 |
| 6.2 | 載台1 檢測軸原點復歸 | Vis_X, Vis_Z, Handle_Z1, Handle_1, Handle_2, Handle_3, Handle_4 | 所有軸原點完成 | 並行 |
| 6.3 | 載台2 檢測軸原點復歸 | Slot_Z, Solt_X, Solt_Y1, Solt_Y2, Inner_X1, Inner_X2, SLight_X1, SLight_X2 | 所有軸原點完成 | 並行 |
| 6.4 | Y52 雷射軸原點復歸 | Laser_Z | 原點完成 | 並行 |
| 6.5 | 開門模組軸原點復歸 | HLight_Z1, DCheck | 兩軸原點完成 | 並行 |

**說明**：其餘軸則無任何分組與限制，收到原點復歸訊號後會直接進行原點復歸

---

#### 第七組：氣缸復歸（等待 Conv_Y1/Y2 原點復歸完成）

| Step | 動作描述 | 涉及氣缸 | 完成條件 | 依賴條件 |
|------|---------|---------|---------|---------|
| 7.1 | 入料 Buffer 區氣缸復歸 | Out515/Out600 | 上升到上位（In112/113/114 = TRUE） | 等待 Conv_Y1 原點完成 |
| 7.2 | 出料 Buffer 區氣缸復歸 | Out601/Out602 | 下降到下位（In307/308/309 = TRUE） | 等待 Conv_Y2 原點完成 |
| 7.3 | 載台1 定位氣缸復歸 | Out509/Out510 | 縮回（In101 = TRUE） | 並行 |
| 7.4 | 載台2 定位氣缸復歸 | Out511/Out512 | 縮回（In103 = TRUE） | 並行 |
| 7.5 | 天車氣缸復歸 | Out606/Out607, Out608/Out609 | X氣缸撐開（In202=TRUE），夾料鬆開（In206/207=TRUE） | 並行 |
| 7.6 | 開蓋平台氣缸復歸 | Out610/Out611 | 關閉位置（In212/213=TRUE，In214=TRUE） | 並行 |

**關鍵依賴**：
```
入/出料 Buffer 區須等到 Conv_Y1/Y2 回到原點後才能進行復歸
```

---

### 原點復歸依賴關係圖

```
時間軸：

T0: 開始原點復歸
    ├─ Valve_X 復歸（必須先完成）
    ├─ DCheck_R1/R2 復歸（必須先完成）
    └─ 其他無依賴軸並行復歸

T1: Valve_X 完成
    └─ Conv_Y1 可以移動 ✅

T2: DCheck_R1/R2 完成
    └─ Door_X 復歸 + 移動到指定位置

T3: Door_X 到達指定位置
    ├─ Conv_Y1 復歸 ✅
    └─ Conv_Y2 復歸 ✅

T4: Conv_Y1/Y2 原點完成
    ├─ Conv_Y1 → 移動到旋轉工作位置
    ├─ Conv_Y2 → 移動到旋轉工作位置
    ├─ 入料 Buffer 氣缸復歸 ✅
    └─ 出料 Buffer 氣缸復歸 ✅

T5: Conv_Y1/Y2 到達旋轉工作位置
    ├─ Conv_R1 復歸 ✅
    └─ Conv_R2 復歸 ✅

T6: 所有軸與氣缸復歸完成
    └─ 設定 HomeReturnCompleted = TRUE
```

---

### 輸出結果
- `Done`: 所有軸與氣缸已復歸完成
- `Status`: HomeReturnCompleted = TRUE，設備可切換到作業模式
- `Position`: 所有軸在原點或指定安全位置，所有氣缸在初始位置

### 備註
- 原點復歸流程必須**嚴格按照分組順序**執行，避免碰撞
- 若任一軸復歸失敗，應中斷流程並報警
- 完成後設備進入待機狀態，可接受入料指令

# 1. 基礎流程

## SEQ-001: 入料流程

### 功能
從入料位置取得工件（Foup 門板）並移動到載台1待處理位置。

### 前置條件
- [ ] Conv_R1 在 0 度位置
- [ ] Conv_Y1 在安全位置
- [ ] 入料位置有工件（In110 = TRUE）
- [ ] 入料 Buffer 氣缸在上位置（In112/In113/In114 = TRUE）
- [ ] 載台1 無工件（In010/In011/In012 = FALSE）
- [ ] 入料光柵靜音未觸發（或已解除）

### 涉及元件
- **軸**: Conv_Y1, Conv_R1
- **氣缸**: 入料 Buffer 區氣缸（Out515/Out600）, 載台1產品定位氣缸（Out509/Out510）
- **感測器**: In110（入料Buffer在席）, In112/113/114（入料Buffer上位）, In304/305/306（入料Buffer下位）, In010/011/012（載台1在席）, In100/101（載台1定位氣缸）

### PC 介面
- **RFID 讀取流程**：參考 55-operation-interface.md
- **Zone 資料管理**：參考 52-pc1-data-buffer-framework.md

### 動作步驟

| Step | 動作描述 | 控制邏輯 | 完成條件 | 備註 |
|------|---------|---------|---------|------|
| 1 | 確認初始狀態 | - | In112/113/114 = TRUE, In110 = TRUE | 入料Buffer氣缸在上位且有工件 |
| 2 | Conv_Y1 移動到入料位置 | Move(Conv_Y1_Load) | Conv_Y1 InPosition | 軸定位完成 |
| 3 | 入料 Buffer 區氣缸下降 | Out515=FALSE, Out600=TRUE | In304/305/306 = TRUE（逾時3秒） | Buffer 氣缸下降到位 |
| 4 | 等待工件穩定 | - | In010/011/012 = TRUE | 載台1在席感測器確認 |
| 5 | RFID 讀取流程 | → 參考 55.md | MR909 = TRUE | PC1 讀取 RFID 完成 |
| 6 | 載台1產品定位氣缸伸出（鎖定） | Out509=TRUE, Out510=FALSE | In100 = TRUE（逾時2秒） | 定位氣缸鎖定 |
| 7 | 入料 Buffer 區氣缸上升 | Out515=TRUE, Out600=FALSE | In112/113/114 = TRUE（逾時3秒） | Buffer 氣缸回到上位 |
| 8 | Conv_Y1 移動到安全/待機位置 | Move(Conv_Y1_Safe) | Conv_Y1 InPosition | 軸離開入料區 |

### 關鍵位置參數

| 位置名稱 | 變數名 | 用途 | 說明 |
|---------|--------|------|------|
| 安全位置 | Conv_Y1_Safe | Step 8 | 待機/安全位置 |
| 入料位置 | Conv_Y1_Load | Step 2 | 入料Buffer取料 |

### 輸出結果
- `Done`: 工件已放置到載台1，定位氣缸已鎖定
- `Status`: Conv_Y1 在安全位置，載台1 有工件且已定位
- `Zone`: Zone1 資料已更新（RFID、目標站別）

## SEQ-002: 出料流程

### 功能
將載台2上的工件（Foup 門板）取出並移動到出料 Buffer 區。

### 前置條件
- [ ] Conv_R2 在 0 度位置
- [ ] 載台2 有工件（In013/In014/In015 = TRUE）
- [ ] 載台2 定位氣缸鎖定（In102 = TRUE）
- [ ] 出料 Buffer 在下位置（In307/In308/In309 = TRUE）
- [ ] 出料 Buffer 無工件（In111 = FALSE）
- [ ] 出料光柵靜音未觸發（或已解除）

### 涉及元件
- **軸**: Conv_Y2, Conv_R2
- **氣缸**: 出料 Buffer 區氣缸（Out601/Out602）, 載台2產品定位氣缸（Out511/Out512）
- **感測器**: In013/014/015（載台2在席）, In102/103（載台2定位氣缸）, In115/200/201（出料Buffer上位）, In307/308/309（出料Buffer下位）, In111（出料Buffer在席）

### PC 介面
- **出料完成通知**：參考 55-operation-interface.md

### 動作步驟

| Step | 動作描述 | 控制邏輯 | 完成條件 | 備註 |
|------|---------|---------|---------|------|
| 1 | 確認初始狀態 | - | In307/308/309 = TRUE, In102 = TRUE | 載台2有工件且已定位 |
| 2 | Conv_Y2 移動到出料位置 | Move(Conv_Y2_Unload) | Conv_Y2 InPosition | 軸定位完成 |
| 3 | 載台2產品定位氣缸縮回（解除） | Out511=FALSE, Out512=TRUE | In103 = TRUE（逾時2秒） | 解除定位鎖定 |
| 4 | 出料 Buffer 區氣缸上升 | Out601=TRUE, Out602=FALSE | In115/200/201 = TRUE（逾時3秒） | Buffer 氣缸夾持工件上升 |
| 5 | 等待工件穩定並確認 | - | In111 = TRUE | 出料Buffer在席確認 |
| 6 | 確認載台2無工件 | - | In013/014/015 = FALSE | 載台2已清空 |
| 7 | 通知 PC 出料完成 | → 參考 55.md | - | 設定出料完成旗標 |
| 8 | Conv_Y2 移動到預備位置 | Move(Conv_Y2_Ready) | Conv_Y2 InPosition | 軸離開出料區 |

### 關鍵位置參數

| 位置名稱 | 變數名 | 用途 | 說明 |
|---------|--------|------|------|
| 預備位置 | Conv_Y2_Ready | Step 8 | 預備/待機位置 |
| 出料位置 | Conv_Y2_Unload | Step 2 | 出料Buffer放料 |

### 輸出結果
- `Done`: 工件已移動到出料 Buffer，載台2 已清空
- `Status`: Conv_Y2 在預備位置，出料 Buffer 有工件
- `Zone`: Zone 資料已清空

## SEQ-003: 搬運流程

### 功能
使用天車系統將工件從載台1搬運到載台2（或開蓋平台/載台3）。

### 前置條件
- [ ] Conv_X 在待機位置
- [ ] Conv_Z 在運輸高度
- [ ] 天車X氣缸在撐開位（In202 = TRUE）
- [ ] 天車夾料氣缸在解除狀態（In206/In207 = TRUE）
- [ ] 起始位置有工件（例如：載台1 In010/011/012 = TRUE）
- [ ] 目標位置無工件（例如：載台2 In013/014/015 = FALSE）
- [ ] 起始位置載台在搬運位置（例如：Conv_Y1 在搬運位置）

### 涉及元件
- **軸**: Conv_X（天車 X 軸）, Conv_Z（天車 Z 軸）, Conv_Y1/Conv_Y2（載台定位軸）
- **氣缸**: 天車X氣缸（Out606/Out607）, 天車夾料氣缸（Out608/Out609）
- **感測器**: In109（天車在席）, In202/203（天車X氣缸）, In204/205（夾料氣缸鎖定）, In206/207（夾料氣缸解除）, 載台1 在席（In010/011/012）, 載台2 在席（In013/014/015）

### 動作步驟

| Step | 動作描述 | 控制邏輯 | 完成條件 | 備註 |
|------|---------|---------|---------|------|
| 1 | 確認天車初始狀態 | - | Conv_Z 在運輸高度, In202 = TRUE, In206/207 = TRUE | 天車在上位且夾爪解除 |
| 2 | Conv_X 移動到起始位置（載台1）上方 | Move(Conv_X_Stage1) | Conv_X InPosition | X 軸定位 |
| 3 | 天車X氣缸縮回 | Out606=FALSE, Out607=TRUE | In203 = TRUE（逾時2秒） | 氣缸下降到位 |
| 4 | Conv_Z 下降到夾取高度 | Move(Conv_Z_Grip) | Conv_Z InPosition | Z 軸下降到位 |
| 5 | 載台定位氣缸解除 | Out509=FALSE, Out510=TRUE | In101 = TRUE（逾時2秒） | 解除載台1定位鎖定 |
| 6 | 天車夾料氣缸鎖定（夾緊） | Out608=TRUE, Out609=FALSE | In204/205 = TRUE（逾時2秒） | 夾緊工件 |
| 7 | 等待夾持穩定 | - | Delay 0.5s | 確保夾持牢固 |
| 8 | Conv_Z 上升到運輸高度 | Move(Conv_Z_Transport) | Conv_Z InPosition | Z 軸上升到位 |
| 9 | 天車X氣缸撐開 | Out606=TRUE, Out607=FALSE | In202 = TRUE（逾時2秒） | 氣缸上升到位 |
| 10 | Conv_X 移動到待機位置 | Move(Conv_X_Standby) | Conv_X InPosition | 避開載台區域 |
| 11 | 確認目標載台在搬運位置 | - | Conv_Y2 在搬運位置 | 確保目標載台就位 |
| 12 | Conv_X 移動到目標位置（載台2）上方 | Move(Conv_X_Stage2) | Conv_X InPosition | X 軸移動搬運 |
| 13 | 天車X氣缸縮回 | Out606=FALSE, Out607=TRUE | In203 = TRUE（逾時2秒） | 氣缸下降到位 |
| 14 | Conv_Z 下降到放置高度 | Move(Conv_Z_Place) | Conv_Z InPosition | Z 軸下降到位 |
| 15 | 載台定位氣缸伸出（鎖定） | Out511=TRUE, Out512=FALSE | In102 = TRUE（逾時2秒） | 鎖定載台2定位 |
| 16 | 天車夾料氣缸解除（鬆開） | Out608=FALSE, Out609=TRUE | In206/207 = TRUE（逾時2秒） | 釋放工件 |
| 17 | 等待工件放穩 | - | In013/014/015 = TRUE | 確認工件到位 |
| 18 | Conv_Z 上升到運輸高度 | Move(Conv_Z_Transport) | Conv_Z InPosition | Z 軸上升避開工件 |
| 19 | 天車X氣缸撐開 | Out606=TRUE, Out607=FALSE | In202 = TRUE（逾時2秒） | 氣缸上升到位 |
| 20 | Conv_X 回到待機位置 | Move(Conv_X_Standby) | Conv_X InPosition | 天車回到待命 |

### 關鍵位置參數

| 位置名稱 | 變數名 | 用途 | 說明 |
|---------|--------|------|------|
| 待機位置 | Conv_X_Standby | Step 10, 20 | 天車待機位置 |
| 載台1上方 | Conv_X_Stage1 | Step 2 | 載台1搬運位置 |
| 載台2上方 | Conv_X_Stage2 | Step 12 | 載台2搬運位置 |
| 開蓋平台上方 | Conv_X_DoorOpen | - | 開蓋平台搬運位置 |
| 運輸高度 | Conv_Z_Transport | Step 8, 18 | 搬運時安全高度 |
| 夾取高度 | Conv_Z_Grip | Step 4 | 夾取工件高度 |
| 放置高度 | Conv_Z_Place | Step 14 | 放置工件高度 |

### 輸出結果
- `Done`: 工件已從起始位置搬運到目標位置
- `Status`: 天車在待機位置，準備下次搬運

### 備註
- 本序列為通用搬運模板，實際使用時需指定起始位置和目標位置
- 可變參數：起始 XZ 座標、目標 XZ 座標、夾取高度、放置高度
- 可根據不同搬運需求調整為：
  - 載台1 → 載台2
  - 載台1 → 載台3（開蓋平台）
  - 載台3（開蓋平台）→ 載台2
  - 載台2 → 載台1（回流）

# 3. 異常處理流程

## SEQ-004: 全機退料流程（自動清線）

### 功能
在非作業模式下，將設備內所有站別的產品全部退出，無論檢測進度如何。

### 適用情境
- 設備進入異常狀態，需清空所有工件
- 維護保養前需清空設備
- 緊急停機後的復原處理
- 切換料號前的清線作業

### 前置條件
- [ ] 設備已切換到**非作業模式**（OperationMode = 0 或 1）
- [ ] 操作員已確認執行全機退料
- [ ] 無嚴重安全警報

### 涉及元件
- **所有載台**：載台1、載台2、載台3（開門模組）
- **所有軸**：Conv_Y1/Y2, Conv_R1/R2, Conv_X, Conv_Z, Door_X, DCheck_R1/R2
- **所有氣缸**：入料/出料 Buffer、載台定位、天車、開門模組

### PC 介面
- **退料狀態通知**：參考 55-operation-interface.md
- **狀態碼**：7xx 系列（參考狀態碼對照表 v1.3）

---

### 執行原則

1. **狀態機清空**：非作業模式下，所有檢測序列的狀態機會被清空為 0
2. **序列自然停止**：當前序列完成後會停住不動（因為狀態機為 0）
3. **並行處理**：所有載台同時動作，不衝突的部分並行執行
4. **順序協調**：有衝突的部分（例如天車搬運、Buffer佔用）會依序等待
5. **開門處理**：若載台3有門板（開門中），會先執行關門再退料

---

### 動作步驟

#### 階段 1：啟動全機退料

| Step | 動作描述 | 控制邏輯 | 備註 |
|------|---------|---------|------|
| 1.1 | 操作員確認執行全機退料 | - | 人工觸發或 PC 指令 |
| 1.2 | 確認設備在非作業模式 | OperationMode = 0 或 1 | 若不是則先切換 |
| 1.3 | 設定全機退料旗標 | 7xx 狀態碼啟動 | 參考狀態碼對照表 |

#### 階段 2：判斷各載台狀態（並行檢查）

| Step | 檢查項目 | 判斷條件 | 後續動作 |
|------|---------|---------|---------|
| 2.1 | 載台1是否有工件 | In010/011/012 = TRUE? | 有→標記需退料 |
| 2.2 | 載台2是否有工件 | In013/014/015 = TRUE? | 有→標記需退料 |
| 2.3 | 載台3是否有門板 | In208/209 = TRUE? | 有→標記需關門+退料 |

#### 階段 3：執行退料動作（並行 + 順序協調）

**載台1 退料流程**（若有工件）：
| Step | 動作描述 | 控制邏輯 | 完成條件 |
|------|---------|---------|---------|
| 3.1 | 中止當前序列 | 清空序列狀態 | 立即 |
| 3.2 | Conv_R1 旋轉至搬運姿態（0度） | Move(Conv_R1_Pos1) | Conv_R1 InPosition |
| 3.3 | Conv_Y1 移動到搬運位置 | Move(Conv_Y1_Carry) | Conv_Y1 InPosition |
| 3.4 | 等待天車搬運 | 執行 SEQ-003（載台1→載台2） | 搬運完成 |

**載台3 關門流程**（若有門板）：
| Step | 動作描述 | 控制邏輯 | 完成條件 |
|------|---------|---------|---------|
| 3.5 | 中止當前序列 | 清空序列狀態 | 立即 |
| 3.6 | DCheck_R1/R2 回正到可關閉位置 | 根據當前角度回正 | 兩軸到位 |
| 3.7 | 等待載台2協同 | 載台2移動到關門位置 | 雙方就位 |
| 3.8 | 執行 SEQ-302（關門流程） | 協作關門 | 關門完成 |
| 3.9 | 天車搬運工件到載台2 | 執行 SEQ-003（載台3→載台2） | 搬運完成 |

**載台2 出料流程**（若有工件或接收工件）：
| Step | 動作描述 | 控制邏輯 | 完成條件 |
|------|---------|---------|---------|
| 3.10 | 中止當前序列 | 清空序列狀態 | 立即 |
| 3.11 | 退出當前檢測站（若在9~11站） | 根據 DM30024 執行退站 | 退站完成 |
| 3.12 | 等待所有工件到達載台2 | - | 載台1/3工件已搬運 |
| 3.13 | 依序執行 SEQ-002（出料流程） | 逐一出料 | 所有工件退出 |

---

### 退料順序協調

**優先順序**：載台3（開門中） → 載台2 → 載台1

```
並行處理時間軸：

T0: 啟動全機退料
    ├─ 載台1：判斷有工件 → 準備退料
    ├─ 載台2：判斷有工件 → 準備退料
    └─ 載台3：判斷有門板 → 需先關門

T1: 載台3 優先處理（開門中）
    ├─ DCheck_R1/R2 回正
    ├─ 載台2 配合移動到關門位置
    └─ 執行 SEQ-302 關門

T2: 載台3 關門完成
    └─ 天車搬運載台3工件到載台2

T3: 天車搬運載台1工件到載台2
    └─ （等待載台2空間釋放）

T4: 載台2 依序出料
    ├─ 出料第一個工件（載台3的）
    ├─ 出料第二個工件（載台2原有的）
    └─ 出料第三個工件（載台1的）

T5: 全機退料完成
    └─ 所有載台清空
```

---

### 輸出結果
- `Done`: 所有工件已退出設備
- `Status`: 所有載台已清空（載台1/2/3 無工件）
- `Action`: 需執行 SEQ-000（原點復歸）才能切回作業模式

### 備註
- 全機退料完成後，**必須執行原點復歸**才能切換回作業模式
- 不接受新產品投入（入料Buffer被禁用）
- 若中途發生嚴重警報，應先處理警報再繼續退料
- 詳細狀態碼定義參考「狀態碼對照表 v1.3」

## SEQ-005: 單一產品退料流程

### 功能
在正常生產流程中，針對特定工件進行退料，不中斷其他工件的生產。

### 適用情境

| 流程中斷 | 完全中斷 | 不中斷其他工件 |

| 前置條件 | 需切換到非作業模式 | 正常作業模式下執行 |

#### 情境 C：載台3 發現異常

**觸發方式**：PC1 在載台3檢測（12~13站）時判定 NG，通知 PLC 與載台2

| Step | 動作描述 | 控制邏輯 | 完成條件 | 備註 |
|------|---------|---------|---------|------|
| C1 | PLC 收到 PC 退料指令 | → 參考 53.md | - | PC Done 回應含退料標記 |
| C2 | 標記 Zone3 為異常 | Zone3 異常旗標 = TRUE | - | 參考 52.md |
| C3 | 載台3 通知載台2進入退料協同 | 狀態碼 801 | 雙方同步 | 參考狀態碼對照表 |
| C4 | 載台3 立即中止當前站作業 | 停止檢測 | 立即 | 例如停止站12 |
| C5 | 載台3 執行回正作業 | 根據 DM30026 | 回正完成 | 門回正到可關閉位置 |
| C6 | 載台2 執行退站作業（若需要） | 根據 DM30024 | 退站完成 | 若在9~11站中 |
| C7 | 載台2 調整到關門預備位置 | 狀態碼 803 | 位置就位 | 準備關門 |
| C8 | 載台3 移動到關門位置 | 狀態碼 806 | 位置就位 | 準備關門 |
| C9 | 雙方協同執行關門 | 狀態碼 805/806 同步 | 關門完成 | 執行 SEQ-302 |
| C10 | 載台2 執行出料 | 狀態碼 810 | 出料完成 | 異常產品退出 |
| C11 | 載台3 排料協同完成 | 狀態碼 811 | 協同結束 | 載台3回到預備位置 |
| C12 | 清空 Zone3 異常標記 | Zone3 異常旗標 = FALSE | - | 恢復正常 |

**關鍵特點**：
- ✅ 載台3 與載台2 協同退料
- ✅ 需要先關門再出料
- ✅ 不影響其他產品

### DM 記憶體管理

**DM30024（載台2 站別記錄）**：
- 更新規則：只記錄 9/10/11 站
- 清空時機：進入 555（等待入料）或 992（開門流程結束）
- 用途：802 退站作業判斷

**DM30026（載台3 站別記錄）**：
- 更新規則：只記錄 12/13 站
- 清空時機：進入 991/992/998
- 用途：802 回正作業判斷

**範例**：
```
載台2 在站10作業中：DM30024 = 10
收到異常 → 801 → 802 根據 DM30024=10 執行站10退站

載台3 在站12作業中：DM30026 = 12
收到異常 → 801 → 802 根據 DM30026=12 執行站12回正
```

---

### 關門同步機制

**同步條件**：
```
IF (載台2狀態碼 = 805) AND (載台3狀態碼 = 806) THEN
    雙方就位，執行 SEQ-302 關門動作
END IF
```

**關門後狀態**：
```
載台2：805 → 810（出料）→ 555（等待入料）
載台3：806 → 811（協同完成）→ 991（回到預備位置）
```

### 輸出結果
- `Done`: 異常工件已退出設備
- `Status`: 載台恢復正常狀態，可繼續處理其他工件
- `Zone`: 異常 Zone 資料已清空

### 備註
- 單一產品退料不影響其他工件的正常流程
- 若多個工件同時需退料，依序處理（排隊機制）
- 詳細狀態碼定義參考「狀態碼對照表 v1.3」
